📚 Template 02 — Prompt Library
▼ How to use this template

What this template is for

  • Your master reference for every reusable AI prompt across all client work.
  • Keeps prompts indexed, categorised, and version-controlled so you never lose a high-performing prompt.
  • Shareable with team members or contractors — consistent prompts = consistent output quality.

How to fill it in

Step-by-step workflow

  • Step 1 — Keep one master file. Do not create per-client copies — this is your agency-wide library.
  • Step 2 — When you discover a prompt that reliably works, add it immediately. Don't let good prompts live only in chat history.
  • Step 3 — Update the index table on Page 1 first, then add the detail card on Page 2 (duplicate a card block).
  • Step 4 — When you improve an existing prompt, update the text and increment the date. Do not delete the old version — add a note in Limitations.
  • Step 5 — Print to PDF monthly as an archived snapshot. Keep the HTML as the live working version.
💡 Pro tip: Colour-code categories consistently. If you use orange for Sales in the index, use the same orange tag in every card. The template already uses pre-set tag classes (.cat-tag.orange, .blue, .purple, .pink).

  • • Test each prompt before using with a client

  • • Delete old versions — archive instead

P-001
Sales Cold Outreach Email Writer
Prompt Text
You are a senior B2B sales copywriter specialising in AI services. Write a cold outreach email for [AGENCY NAME] to [TARGET COMPANY]. The email should: (1) open with a specific insight about their business, (2) clearly state one problem we solve, (3) provide one credible proof point, (4) end with a low-friction CTA (15-minute call). Tone: professional but conversational. Length: under 150 words. Do not use buzzwords like "leverage" or "synergy".
Variables to Replace
[AGENCY NAME], [TARGET COMPANY], [PAIN POINT], [PROOF POINT]
Recommended Model
GPT-4o / Claude 3.5 Sonnet
Quality Rating
⭐⭐⭐⭐ (4/5)
Known Limitations / Notes
May over-formalise tone for some industries. Test on 3–5 variations before large-scale use.
P-002
Content LinkedIn Post Generator
Prompt Text
Act as a thought-leadership ghostwriter for [AUTHOR NAME], an AI agency founder. Write a LinkedIn post about [TOPIC]. Structure: hook (1 line) → insight (2–3 short paragraphs) → takeaway or question (1 line). Style: direct, no fluff, no emojis except sparingly, no "I'm excited to share" openers. Add 3 relevant hashtags at the end. Max 250 words.
Variables to Replace
[AUTHOR NAME], [TOPIC], [TONE: direct / inspirational / educational]
Recommended Model
Claude 3.5 Sonnet
Quality Rating
⭐⭐⭐⭐⭐ (5/5)
Known Limitations / Notes
Works best when given a specific angle or story. Generic topic inputs produce generic output.
P-003
Ops Client Report Summariser
Prompt Text
You are an account manager at an AI agency. Summarise the following project update for a non-technical client in [CLIENT NAME]'s industry. Output format: (1) Status in one sentence, (2) What we completed this week (bullet list, max 5 items), (3) What's happening next week (bullet list, max 3 items), (4) Any blockers or decisions needed from the client. Keep total length under 200 words. Avoid jargon. [PASTE RAW NOTES HERE]
Variables to Replace
[CLIENT NAME], [CLIENT INDUSTRY], [RAW NOTES / DATA]
Recommended Model
GPT-4o
Quality Rating
⭐⭐⭐⭐ (4/5)
Known Limitations / Notes
Always human-review before sending. Model sometimes omits blockers if notes are too brief.
