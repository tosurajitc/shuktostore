⚙️ Webhook Setup
⚠️ Buyers only appear here after the Razorpay webhook is configured. If the table is empty after a real purchase, follow the steps below.
1
Go to Razorpay Dashboard → Webhooks → Create Webhook
2
Set the URL to https://www.shukto.in/api/webhook/razorpay
3
Select event: payment_link.paid
4
Copy the webhook secret and add it to Railway as RAZORPAY_WEBHOOK_SECRET
✓
Optional: For confirmation emails, add RESEND_API_KEY from resend.com and RESEND_FROM (e.g. hello@shukto.in) to Railway env vars.

💡 How bundles work
1. Create a bundle here — pick the books, set the discounted price, and add a Razorpay payment link for the bundle amount.
2. Each individual book's sales page will automatically show a "Bundle offer" section (via data-sp-bundle) whenever a bundle that contains that book is active.
3. The bundle card shows the combined book titles, the original total crossed out, and the discounted bundle price — with its own "Buy the bundle" button pointing to your Razorpay bundle link.
4. To temporarily hide a bundle, simply delete it from this list. The individual book pages stay unchanged.
