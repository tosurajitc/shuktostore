⚙️ Template 03 — Automation Tracker (Landscape A4)
▼ How to use this template

What this template is for

  • Your single source of truth for every automation running across all client engagements.
  • Track status, ownership, cost, and ROI in one landscape view — update it monthly or after each deployment.
  • Use the ROI summary section to justify automation spend to clients or stakeholders.
  • Click "+ Add Automation Row" below the table to add a new blank row — no need to edit HTML.

Updating the ROI summary

  • Sum all "Time Saved" values → enter in "Time Recovered" card.
  • Sum all "Monthly Cost" values → enter in "Cost of Automations" card.
  • Multiply total hours by your hourly rate → enter in "Value Generated".
  • ROI = (Value − Cost) ÷ Cost × 100. Update monthly.
💡 Print tip: This template is designed for landscape A4. In Chrome's print dialog, set orientation to Landscape. Use "Fit to page" if columns get clipped.
