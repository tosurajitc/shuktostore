How to use your templates

Start with your first client onboarding. Here's the recommended order.

1
Unzip the download folder

You'll find 4 HTML files inside. Keep the folder somewhere accessible — you'll reuse these for every client.

2
Open a template in your browser

Double-click any HTML file to open it in Chrome, Edge, or Safari. You'll see a yellow print bar at the top with the edit hint.

3
Click any dashed field to edit

Fields with a dashed underline are editable. Click once and start typing. The agency name, client details, dates, and all content is yours to customise.

4
Click "Print / Save as PDF" when done

Use the button at the top of the page. In the print dialog, select "Save as PDF" as the destination. For best results, use Chrome and keep default margins.
